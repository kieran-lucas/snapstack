# SnapStack

SnapStack is a Windows utility for capturing multiple screenshots into a session and pasting the entire stack in one action.

## Core workflow

1. Start a capture session.
2. Capture multiple screenshots.
3. Keep the captures ordered in the current session.
4. Paste the full stack with a single command.

## Planned stack

- C# / .NET
- WinUI 3 + Windows App SDK
- Windows.Graphics.Capture + Direct3D 11
- Win32 global hotkeys
- Multi-format Windows clipboard integration

## Status

Early development. The repository is being built incrementally in small, atomic commits.
